# 楼间 · 论坛体小说创作

一个贴吧式的模拟论坛编辑器。所有角色和帖子都是小说创作素材，支持多作品、角色与马甲、楼层编排、引用回复、折叠与删帖效果，以及阅读预览。

## 保存与导出

- 自动保存到当前浏览器的 localStorage，不上传小说内容。
- 导出纯文本和 PNG 长图，不包含作者私密备注。
- JSON 完整备份包含全部作品、角色与备注，可重新导入。
- 切换设备、浏览器或站点地址前，请先导出 JSON 备份。清理浏览器站点数据会清除本地作品。

## 本地运行

```sh
npm ci
npm run dev
```

## GitHub Pages

在仓库 Settings → Pages 中，将 Source 选择为 GitHub Actions。推送到 main 后会自动构建并部署，完成后可在 Actions 的部署任务中打开网址。

```sh
npm run build -- --base=./
```

构建输出为 dist。相对资源路径同时支持 GitHub 项目子目录和独立域名。这个仓库只包含程序与虚构示例，不包含实际用户作品。
